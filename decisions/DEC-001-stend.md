# DEC-001. Стенд: бэкенд из store/, админка из исходников medusa-src/

**Решили.** Бэкенд работает как есть в `store/` (порт 9000, демо-данные).
Админку поднимаем отдельным dev-сервером Vite из
`medusa-src/packages/admin/dashboard/`, он ходит на бэкенд по HTTP.

**Почему.** Нужна живая правка исходников дизайн-системы с HMR. CORS уже
готов: `store/apps/backend/.env:3-4` разрешает origin `localhost:5173`.
Версии сходятся, 2.19.0 с обеих сторон.

**Альтернатива.** Подменить `@medusajs/dashboard` в `store/` на воркспейс
монорепо, чтобы бэкенд сам отдавал админку. Отвергли: это правка `store/`,
а `admin-bundler` собирает продовый бандл в `.medusa/client` — итераций по
исходникам там нет.

**Дата.** 2026-08-28
