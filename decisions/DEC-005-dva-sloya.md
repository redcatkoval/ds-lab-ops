# DEC-005. Карта строится по двум слоям

**Решили.** Считаем оба слоя: системный пакет `@medusajs/ui` и локальный
`dashboard/src/components/`. Результаты — `ds-ops/map/components.json`
и `ds-ops/map/local-components.json`.

**Почему.** Подсчёт по одному пакету даёт ложную картину. Системный
`table` — 2 импорта из 2 файлов, при том что локальные табличные
компоненты берут из 149 файлов (`table/data-table` 84,
`table/configurable-data-table` 35, `data-table` 30). Системный
`skeleton` — 0 импортов, локальный `common/skeleton` — 45 файлов.
Локальных компонентов 126 против 46 системных.

**Альтернатива.** Ограничиться системным слоем — так карта показывала бы
неиспользуемыми компоненты, которые на деле заменены локальными.
