# DEC-002. store/ и medusa-src/ — только чтение

**Частично отменено 2026-09-01 решением DEC-009.** В части `medusa-src/`
не действует: он стал нашим форком, изменения в нём разрешены по
контракту. В части `store/` и в части обращения с lock-файлами
действует по-прежнему.

**Решили.** Исходные файлы не изменяем никогда. Установка зависимостей
разрешена: `node_modules` — производный артефакт, исключённый через
`.gitignore`. Lock-файлы не трогаем, ставим с `--immutable`. Критерий —
пустой `git status --short`, проверяем после каждой операции.

**Почему.** Без установки монорепо неработоспособен. Критерий по git даёт
проверяемую границу вместо интуиции. Работает он только в `medusa-src/` —
в `store/` репозитория нет.

**Альтернатива.** Запретить установку вовсе — нереализуемо. Обратная
крайность, «ставим как придётся», рискует незаметной правкой lock-файла.

**Дата.** 2026-08-28
