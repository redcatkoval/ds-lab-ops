# Q-002. Три табличных компонента с близкими именами

**Вопрос.** В локальном слое три компонента с близкими именами.
Неизвестно, чем они отличаются и почему их три.

| компонент | файлов |
|---|---:|
| `table/data-table` | 84 |
| `table/configurable-data-table` | 35 |
| `data-table` | 30 |

Числа из `ds-ops/map/local-components.json`.

**Что известно.** Только эти числа. Ни назначение, ни различия не
выяснялись: разбор их кода выходит за границы текущего среза
(`ds-ops/slices/2026-08-product-detail/scope.md`).

Одна связь со срезом есть: карточка товара использует `data-table` —
самый редкий из трёх, — в `product-variant-section`.

**Возможные исходы.**
1. Свести в один.
2. Развести по назначению, с явной границей между ними.
3. Оставить как есть, с объяснением, почему их три.

**Когда решать.** После того как готов контракт на самый частый из них
— `table/data-table`. Не раньше: без контракта сравнивать нечем, и любой
из трёх исходов будет догадкой.

**Статус.** Открыт.
