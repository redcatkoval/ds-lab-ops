# Q-004. theme.ts строится только по светлой теме

**Вопрос.** Раскладка в Tailwind собирается перебором ключей светлой
темы. Тёмная тема на состав `theme.ts` не влияет.

**Что известно.** `toolbox/src/commands/tokens/command.ts:360` —
`Object.keys(themeNode.colors.light)`; там же `:424` —
`Object.keys(themeNode.effects.light)` для теней. Сейчас расхождения
нет: все 113 токенов объявлены в обеих темах, только-светлых и
только-тёмных ноль (`ds-ops/tokens/tokens.json`, `counts.only_light`
и `only_dark`). То есть проверка на равенство сегодня проходит, но она
ничем не обеспечена.

**Кому адресован.** Дизайн-система: генератор её.

**Статус.** Открыт.
