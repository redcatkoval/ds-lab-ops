# Q-005. Ветки тем несимметричны

**Вопрос.** Две ветки переключения тем применяют разный набор.
В ветке с классом объявляются только `colors.dark` и `effects.dark`
(`ui-preset/src/plugin.ts:30`). В ветке с media-запросом к ним
добавляется `components.dark` (`plugin.ts:36`).

**Что известно.** Потребитель работает по первой ветке:
`dashboard/tailwind.config.cjs:14` задаёт `darkMode: "class"`.
Последствий сейчас нет — `ui-preset/src/theme/tokens/components.ts`
пуст, `{"dark": {}, "light": {}}`, компонентных классов ноль в обеих
темах. Генератор кладёт туда классы линейных градиентов
(`toolbox/src/commands/tokens/command.ts:245`), в текущей выгрузке
градиентов нет.

**Кому адресован.** Дизайн-система: обе ветки в её плагине.

**Статус.** Открыт.
